# PHAZE v0.1.1 — проверка 22 ноября 2026

## Публичная сборка

На GitHub Pages открыт https://studio1037.github.io/studio1037-phaze/. В Chrome проверены четыре квадранта, живые часы, создание события длительностью 37 минут со сдвигом 13 минут, редактирование, ежедневное повторение, отдельная отметка выполнения для выбранной даты, сохранение после перезагрузки и перенос относительного события при изменении времени пробуждения. На ширине 1476 и 375 px горизонтальной прокрутки нет. На 375 px также проверены окно настроек и сообщение при отсутствии Google OAuth Client ID.

## Автоматические проверки

- Переход через полночь, летнее и зимнее время Asia/Jerusalem и окно длиной 16 часов.
- Все пять правил повторения. Расчёт занятого времени с пересечениями.
- Экспорт и импорт JSON с восстановлением событий и времени пробуждения. Повреждённый файл отклоняется, текущие данные сохраняются.
- Google Calendar API на тестовых ответах: выбор нескольких календарей, пагинация, запрос развёрнутых экземпляров повторений, защита от записи ответа для уже закрытой даты и сообщение об ошибке 403.
- Service worker с имитацией кэша: загрузка ресурсов, получение страницы и скрипта офлайн, изоляция кэшей других проектов.

## Открытые проверки

Вход с OAuth Client ID владельца и чтение реальных календарей. Установка на физическом Android/iPhone и холодный запуск при отключённой сети. При более чем трёх одновременных событиях одного источника отдельные секторы могут перекрываться, в списке доступны все.
