# PHAZE v0.1.0 — Studio1037

Рабочая PWA для планирования 16 часов бодрствования на круговом циферблате.

## Быстрый запуск

**Без установки:** открой `PHAZE_v0.1.0_standalone.html` в обычном браузере на компьютере. Для стабильного использования на iPhone/iPad рекомендуется опубликованный HTTPS-сайт.

**Публикация:** загрузи содержимое папки `PHAZE_v0_1_0` в отдельный репозиторий GitHub, включи GitHub Pages или подключи Cloudflare Pages. Стартовый файл — `index.html`. Service Worker включается автоматически в HTTPS.

## Уже работает

- Циферблат: 16 часов, отметки 0/16, 4, 8, 12; сектора с точностью до минут.
- Цифровые текущие часы 12-hour AM/PM и стрелка текущего момента.
- Переключение дат, изменение времени начала бодрствования, интервалы событий.
- Нажатие на свободную дугу создаёт событие в соответствующий момент; кнопка «+ Событие» делает то же через форму.
- Повторения: ежедневно; выбранные дни недели; каждые N дней с заданной даты; конкретные даты; однократно.
- Цветовые категории и пометка выполнения для конкретного дня.
- Статистика запланированного и свободного времени (пересечения не удваиваются).
- Локальное хранение в LocalStorage, экспорт и импорт JSON.
- Google Calendar API: режим чтения событий нескольких выбранных календарей после OAuth-настройки; отдельное кольцо для Google-событий.

## Настройка Google Calendar (однократно на опубликованном домене)

1. Создать Google Cloud Project в https://console.cloud.google.com/.
2. Включить Google Calendar API.
3. Настроить OAuth consent screen. Для личного тестирования добавить себя в тестовые пользователи, если требуется.
4. Создать OAuth Client ID типа **Web application**. В **Authorized JavaScript origins** указать точный origin опубликованного сайта, например `https://username.github.io` или `https://phaze.example.com` (без пути). При смене домена добавить новый origin.
5. Открыть PHAZE → ⚙ → ввести Client ID → «Подключить Google». Предоставить только **чтение** календарей.
6. Выбрать необходимые календари и нажать «Обновить». Важно: PHAZE не записывает события в Google Calendar.

Подключение Google Calendar в чате ChatGPT **не** передаёт авторизационные токены в независимую PWA. OAuth Client ID не является client secret; секретов в исходном коде быть не должно.

Google Calendar `calendar.readonly` может потребовать дополнительной проверки OAuth-приложения для широкой публикации за пределами тестовых пользователей. Для персонального использования начни с тестового режима.

## Данные и конфиденциальность

Локальные события, время пробуждения и кэш полученных Google-событий сохраняются в LocalStorage браузера. Токен Google хранится только в памяти открытой страницы и не сохраняется. При очистке данных браузера локальные записи могут исчезнуть — регулярно делай экспорт JSON. В экспорт не включается кэш Google-событий.

## Ограничения v0.1.0

- Полноценной синхронизации PHAZE между устройствами пока нет.
- Google Calendar: только чтение, OAuth требует настройки своего Google Cloud проекта.
- События Google, целиком занимающие весь день, отображаются в списке, а не «закрашивают» все 16 часов.
- Метрика «Отмечено» — вручную отмеченные выполненные интервалы, а не измеренное фактическое время и не продуктивность.
- Редактирование повторяющегося события меняет всю серию. Отдельные исключения и перенос экземпляров пока не реализованы.
- День фиксирован 16 часами; индивидуальное время сна/пробуждения по дням пока не поддерживается.
- Прототип проверен в автоматизированном Chromium на мобильной ширине. Живой OAuth с реальным аккаунтом и поведение Safari/iOS ещё требуют пользовательской проверки.

## Тестовый сценарий

1. Создай «Дети → школа» на 120 минут, старт «от пробуждения», ежедневно.
2. Создай «Работа» на 90 минут по обычным часам, каждый понедельник.
3. Создай «Восстановление» на 45 минут, каждые три дня с выбранной даты.
4. Переключи несколько дат и проверь цвета, занятую и свободную долю.
5. Отметь событие выполненным — счётчик «Отмечено» должен увеличиться только для текущей даты.
6. Измени пробуждение в настройках — относительные события должны сдвинуться вместе с ним.
7. Проверь экспорт/импорт JSON и установку PWA на телефон.
