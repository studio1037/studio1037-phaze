# PHAZE v0.1.1

Циферблат на 16 часов от пробуждения. Время отображается в Asia/Jerusalem. Свои события хранятся в браузере. Настройки → Экспорт JSON и Импорт JSON переносят события и время пробуждения. Перенеси резервную копию при переходе с HTML-прототипа на сайт.

## Google Calendar

1. В [Google Cloud Console](https://console.cloud.google.com/) выбери или создай проект PHAZE и включи **Google Calendar API**.
2. В **Google Auth Platform → Branding** задай имя приложения и контакты. В **Audience** выбери External для личного Google-аккаунта. В режиме Testing добавь адрес аккаунта в Test users.
3. В **Data Access** добавь scope `https://www.googleapis.com/auth/calendar.readonly`.
4. В **Clients → Create client** выбери Web application. В **Authorized JavaScript origins** добавь origin сайта, например `https://studio1037.github.io` для GitHub Pages. Укажи только схему и домен, без пути репозитория и завершающего слэша. Redirect URI для этого потока не нужен.
5. Скопируй **Client ID** в **Настройки → Google OAuth Client ID**, нажми **Подключить Google** и выбери календари. Client Secret приложению не нужен. При истечении токена или после перезагрузки нажми «Подключить Google» снова.

Запросы к Calendar API выполняются в браузере. Токен хранится в памяти вкладки. Кэш событий доступен офлайн и его можно очистить в настройках. События на весь день отображаются списком. Первые три пересекающихся события каждого источника могут занимать отдельные дорожки. При большем числе часть секторов накладывается, а полный список доступен ниже.

## Запуск

В корне проекта запусти `python3 -m http.server 8765` и открой http://localhost:8765. Для установки используй меню браузера или «На экран Домой» в Safari. После первой загрузки дождись регистрации service worker перед проверкой офлайн. При обновлении закрой все открытые вкладки PHAZE и запусти снова.
